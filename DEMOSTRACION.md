# Demostración del flujo operativo

Duración sugerida: entre tres y cinco minutos. Mostrar la aplicación y el repositorio durante la exposición. Este guion no constituye una grabación de video.

1. Abrir main.py con Python o el ejecutable distribuido. Mostrar PSeInt como origen y Python como destino.
2. Pulsar «Si / Entonces». Explicar que la plantilla escribe un programa completo y activa el controlador de traducción existente.
3. Señalar la declaración de edad, su asignación a 18 y la condición edad >= 18. Comparar con el if/else generado en el panel derecho.
4. Mostrar el estado «Sincronizado · revisar advertencias». Leer el mensaje: aceptar la sintaxis no prueba la corrección completa del algoritmo.
5. Pulsar «Copiar Python» y mostrar «¡Copiado!». Usar «Descargar .py» para guardar demostracion.py en una carpeta elegida.
6. Cambiar edad <- 18 a edad <- 15. Mostrar «Cambios pendientes». Pulsar Ctrl+Enter y guardar nuevamente. El programa generado imprime «Menor de edad» si se ejecuta por separado; el traductor no lo ejecuta.
7. Abrir la guía visual, cambiar el tema y arrastrar el divisor para mostrar los controles de la interfaz.
8. Para mostrar un error, eliminar FinAlgoritmo y pulsar Traducir. El motor informa el error y deja vacía la salida; no conserva una traducción anterior como si fuera válida. Recuperar el ejemplo con la plantilla.
9. En el repositorio, abrir EVIDENCIAS.md y las carpetas de los tres casos. Mostrar entrada, traducción, salida observada y captura.
10. Cerrar mostrando PENDIENTES.md y explicar las limitaciones de compatibilidad.

Para una presentación reproducible, empezar sin datos propios que puedan reemplazarse. Las confirmaciones de reemplazo y guardado forman parte del comportamiento de la aplicación. Si el docente solicita video, grabar este recorrido; no hay un video incluido en esta entrega.
